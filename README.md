# FlexFit Club

Frontend website for FlexFit Club, built with React 18, TypeScript, Bootstrap 5, and React Router v6.

## Run locally

```bash
npm run install:all
npm run dev
```

Client: `http://localhost:5173`

## Replace client assets

Images live under `client/public/assets/images`. Replace gym photos, trainer photos, and gallery photos using the same filenames when client assets are ready.
